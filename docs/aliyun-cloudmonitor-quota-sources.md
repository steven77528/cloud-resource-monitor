# 阿里云云监控 API 额度核验依据

核验日期：2026-09-08。适用对象为本项目使用的 `Cms 2019-01-01 DescribeMetricList`，命名空间包括 `acs_oss_dashboard` 和 `acs_slb_dashboard`。该接口官方文档归属云监控 1.0。本文没有把云监控 2.0、Prometheus、实时数据导出或智能阈值服务的计费方式套用于本项目。

## 已核实的规则

| 问题 | 官方规则与本项目含义 |
| --- | --- |
| 每月免费额度 | `DescribeMetricLast`、`DescribeMetricList`、`DescribeMetricData`、`DescribeMetricTop` 合计 **1,000,000 次/月**，不是每个接口各 100 万次。 |
| 统计单位 | 按实际 API 调用次数统计，与返回的数据条数及内容无关。一页请求返回多个历史数据点，不因此按多个数据点收费；继续请求下一页会增加一次请求。 |
| 账号范围 | RAM 用户调用次数累计到所属阿里云账号。不能通过增加 AccessKey、RAM 用户或把同一主账号配置成多个逻辑账号来增加免费额度。核算时应把同一主账号的各地域、各客户端及各实例的这四类接口调用相加，不假设每地域另有 100 万次。 |
| 其他使用者 | Grafana 云监控插件也会消耗同一查询 API 额度。通过阿里云控制台操作产生的调用不计入。旧版 `2018-03-08 QueryMetricList/Last/Data/Top` 同样消耗额度。 |
| 超额后的行为 | 未开通基础云监控按量计费时，免费额度耗尽后可能被限流，不能保证继续采集；已开通时，超出免费额度部分按量收费。 |
| 超额费用 | 官方按量计费文档示例为 **0.12 元/万次**，先抵扣免费额度，按日结算。官方同时说明示例仅供参考，实际费用以购买页面为准。 |
| 每秒速率 | 单个 `DescribeMetricList` API 限制 **50 次/秒**，一个阿里云账号及其 RAM 用户共用。月总量满足，不代表任意瞬时突发都满足。 |
| 批量查询 | `DescribeMetricList` 单次最多批量查询 50 个实例；`Length` 单页最大 1440 条。当前项目按每个指标配置项分别请求，不能把未来可能实现的批量优化算作当前已节省的次数。 |

每月 100 万次是这一组云监控查询接口的免费额度，并非阿里云所有开放 API 的统一总上限。ECS、RDS、域名、证书、费用中心、短信统计等产品接口需要分别核对自身的速率限制。

频率估算需按实际发出的请求计算，包括分页、重试、人工执行单次采集、重启触发采集，以及同一账号中其他系统产生的调用。重试请求是否全部计入账单在本次所查文档中未逐类说明，容量预算应保守预留，而不能假定失败重试免费。

## 实际账号仍需核对的内容

本次依据公开文档及项目配置核算，未使用真实访问密钥，不能读取该账号本月已消耗次数、其他系统用量、历史套餐或自定义配额。上述文档对按账号汇总有明确说明；没有提供每地域单独增加免费额度的依据，因此预算采用主账号合计的保守口径。

官方历史套餐用户可能适用已有 `cms_edition` 套餐额度；国际站价格也可能不同。正式上线应核对该账号的云监控“资源消耗”页面以及实际计费状态。长期容量规划使用 31 天月份估算，可同时给出 30 天月份便于对照；该天数选择是预算方法，不是另一种阿里云计费规则。
